# Google Play Store App Analysis — Tableau

## Overview

This project presents an interactive Tableau dashboard for analyzing Google Play Store applications based on ratings, reviews, prices, installs, content ratings, and other app-related attributes.

## Dashboard Preview

![Google Play Store App Analysis](google%20playstore%20analysis.png)

## Analysis

The Tableau workbook contains the following visualizations:

- Content Rating vs Reviews
- Top 10 Apps by Price
- Top 10 Apps by Rating
- Top 10 Free Apps by Installs

## Dataset

The project uses the **Google Play Store** dataset stored in Excel format.

### Dataset Fields

The dataset includes:

- App
- Category
- Rating
- Reviews
- Size
- Installs
- Installs Numeric
- Type
- Price
- Content Rating
- Genres
